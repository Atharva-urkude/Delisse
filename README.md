# Délisse Studio

Open `index.html` in a modern browser. The menu is `menu.html`. Keep the website files and assets together. No installation or build step is needed.

This is a separate, local version of the supplied project. The production website has not been modified.

## Included

- Cinematic video hero with the original video, content and images.
- Responsive navbar, correctly aligned logo, and clear gutters inside the gingham ribbons.
- Desktop tiramisu doodle cursor, pointer-responsive images and image detail dialogs.
- Tiramisu intro animation, percentage and coffee-and-milk progress bar.
- Optional, locally synthesised ambient music, enabled only by a visitor action.
- Structured address fields, six-digit PIN validation and an address preview.
- Original WhatsApp enquiry flow, serving sizes, descriptions and prices.
- Non-personal bag persistence; delivery details are not saved to local storage.
- Reduced-motion support, keyboard navigation, Escape dismissal and native form validation.

## Verification

Browser layouts checked at 320, 390, 768, 1024 pixels and the desktop viewport. Mobile navigation, video playback, ambient music, day/night mode, image detail dialog, bag persistence and address validation were exercised. No order was sent. JavaScript syntax and order-message tests passed; original product data, homepage text and image/video bytes were checked against the supplied project.

The progress percentage represents the intro sequence, gated by critical-media readiness; it is not a byte-download meter. Ambient music is a quiet synthesised chord texture, not a prerecorded soundtrack. Fonts use Google Fonts with local system fallbacks.

To update the existing live site, upload this folder's contents to the existing host's website root, retaining a backup first. Hosting credentials or a deployment connection were not supplied.
